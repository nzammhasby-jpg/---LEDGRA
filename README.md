# LEDGRA | لِدجرا للمحاسبة السحابية (المرحلة الأولى - البنية التأسيسية) 🚀

منصة سحابية متطورة لإدارة المنشآت والأعمال، تمثل المرحلة الأولى لتأسيس البنية التحتية والمنظومة المحمية الأساسية للمنصة. تشتمل هذه المرحلة على بناء نظام معزول كلياً للمستأجرين المتعددين (Multi-Tenant Isolation) لضمان أعلى مستويات الأمان والخصوصية للمنشآت والشركات وفروعها، بالإضافة إلى رحلة تسجيل حساب وتأسيس منشأة متكاملة.

> ⚠️ **تنويه هام ومسؤول:** هذا المشروع يمثل **المرحلة الأولى الأساسية فقط** (الهيكل والتحقق وإعداد الملف السحابي وحسابات المنشآت والفروع والتحكم في إعداداتها). البرامج والمودولات المحاسبية المتقدمة والتشغيلية (مثل: إصدار الفواتير، إدارة المبيعات والمشتريات، كشف الحساب والقيود اليومية، جرد المخزون، والتقارير المالية والضريبية الختامية) هي أهداف قادمة قيد التطوير النشط في مراحل التطوير التالية ولم تُبنَ في هذه المرحلة.

---

## 🛠️ التقنيات المستخدمة في المشروع

*   **الواجهة الأمامية:** React + Vite
*   **لغة البرمجة:** TypeScript لضمان موثوقية الأنواع وتفادي الأخطاء البرمجية.
*   **التنسيق والتصميم:** Tailwind CSS الموحد والمبسط لضمان واجهة سريعة الاستجابة ومتناسقة الألوان والهوية.
*   **المصادقة وقاعدة البيانات:** Supabase PostgreSQL & Supabase Auth.
*   **إدارة البيانات والاتصال:** TanStack Query (React Query) لإدارة الذاكرة المؤقتة لبيانات المستأجرين.
*   **التأثيرات الحركية:** Motion لضمان تجربة مستخدم سلسة ومرنة.

## 🔒 الامتثال وضوابط الفوترة السعودية (أهداف مستقبلية)

سيكون النظام مهيأً في مراحله المقبلة للامتثال الكامل مع ضوابط لائحة الفوترة الإلكترونية والمتطلبات المعتمدة من قبل الهيئة العامة للزكاة والضريبة والجمارك (ZATCA) في المملكة العربية السعودية للفواتير الضريبية والمبسطة وعمليات الربط والتكامل (Phase 2)، إضافة لتقديم تقارير مالية وتوافقية ممتازة تناسب احتياجات المنشآت السعودية وفق معايير المحاسبة والضريبة المتبعة.

## 📂 هيكلة وتأمين قاعدة بيانات Supabase

لتشغيل هيكل قاعدة البيانات من البداية وبشكل موحد، يرجى تشغيل الملف التالي:

### ١. تشغيل الهيكل والقواعد في Supabase
1. قم بإنشاء مشروع جديد في منصة [Supabase](https://supabase.com).
2. اختر من القائمة الجانبية **SQL Editor** ثم اضغط على **New Query**.
3. انسخ كامل المحتويات من ملف `supabase_schema.sql` وهو الملف الموحد والنهائي والآمن في هذا المشروع.
4. الصق المحتويات بأكملها في المحرر ثم اضغط **Run**.
   - يتولى هذا السكريبت بناء وتجهيز الجداول الأساسية: `profiles`, `organizations`, `organization_members`, `branches`, `notifications`, `audit_logs` وضبط الصلاحيات والهويات الأساسية.
   - يفعّل قواعد الحماية الصارمة **RLS (Row Level Security)** لعزل بيانات كل منشأة عن المستخدمين الآخرين تماماً.
   - يدمج `SET search_path = public, pg_temp` في دوال الـ `SECURITY DEFINER` (مثل دالة `is_member_of` ودالة `handle_new_user`) كتدبير أمني متقدم يمنع ثغرات الاختراق وحقن المسار.

## 🔑 متغيرات البيئة الأساسية (Environment Variables)

يتطلب التطبيق توفير متغيرات البيئة التالية للعمل بشكل صحيح داخل ملف الـ `.env`:

```env
# رابط الاتصال بمشروعك على Supabase
VITE_SUPABASE_URL="https://your-project-id.supabase.co"

# المفتاح العام لـ Supabase (Anon Key)
VITE_SUPABASE_ANON_KEY="your-anon-public-jwt-key"
```

*(ملاحظة: تم إلغاء الاعتماد على متغير البيئة `VITE_APP_URL` حيث يقوم التطبيق بتحديد أصل الرابط تلقائياً باستخدام المتصفح لتبسيط التشغيل دون أخطاء أو تعليق).*

### ⚠️ هام جداً: تفعيل رابط استعادة كلمة المرور (Redirect URL)
لضمان نجاح حركة استعادة وإعادة تعيين كلمة المرور بأمان تام، يجب تسجيل رابط إعادة كلمة المرور كأحد الروابط الموثوقة للتوجيه التلقائي في حسابك على Supabase:
1. اذهب إلى لوحة تحكم **Supabase** لمشروعك.
2. من القائمة الجانبية اختر **Authentication** ثم اذهب إلى قسم **URL Configuration** -> **Redirect URLs**.
3. قم بإضافة رابط التطبيق متبوعاً بمسار استعادة كلمة المرور، على سبيل المثال:
   - في بيئة التطوير المحلية: `http://localhost:3000/#/reset-password`
   - في بيئة النشر الفعلية: `https://your-domain.com/#/reset-password`
4. اضغط على **Save** لحفظ التغييرات بنجاح.

## 💾 سكريبتات التحديث الإضافية (Migrations)

إذا كنت تمتلك قاعدة بيانات سابقة وقمت بإنشائها عبر سكريبت `supabase_schema.sql` الأولي، يرجى تشغيل ملف الهجرة والتعديل الإضافي لإنهاء حالة التكرار وحلقة الـ Onboarding:
1. اذهب إلى **SQL Editor** في لوحة تحكم Supabase.
2. افتح ملف `supabase/migrations/20260617_fix_onboarding_loop.sql` الموجود في المشروع.
3. انسخ محتويات السكريبت بالكامل والصقها في نافذة استعلام جديدة في Supabase ثم اضغط **Run**.
4. يضمن هذا السكريبت ضبط حقول إعدادات المنشأة وتحسين معالج إنشاء المنشأة ليعمل بشكل سليم وثوابت مرجعية دقيقة ومتوافقة كاملة.

## 💻 طريقة تشغيل وتطوير المشروع محلياً

لتشغيل خادم التطوير محلياً واختبار المنصة:

```bash
# ١. تثبيت الحزم والمكتبات المعتمدة
npm install

# ٢. تشغيل خادم التطوير (على المنفذ 3000)
npm run dev

# ٣. بناء نسخة الإنتاج الجاهزة للنشر والتحقق التام من البناء
npm run build

# ٤. فحص سلامة وتوافق أكواد الـ TypeScript والـ Linting
npm run lint
```
