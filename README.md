# LEDGRA | لِدجرا للمحاسبة السحابية 🚀

منصة محاسبية سحابية سعودية متكاملة للمنشآت والأعمال، متماشية مع متطلبات هيئة الزكاة والضريبة والجمارك (ZATCA) للفوترة الإلكترونية.

تم تأسيس هذه المرحلة الأولى بأسلوب **SaaS Premium** احترافي مبني على عزل البيانات الكامل، ودعم وضعي التشغيل (قاعدة بيانات Supabase الحقيقية) و (وضع العرض التجريبي التفاعلي) للتجربة السريعة والمثالية قبل التكوين.

---

## 🛠️ التقنيات المستخدمة في المشروع

*   **الواجهة الأمامية:** React (v19) + Vite
*   **لغة البرمجة:** TypeScript تضمن سلامة الأنواع المالية والمحاسبية.
*   **التنسيق والتصميم:** Tailwind CSS المطور مع الخطوط العربية (Tajawal) والإنجليزية (Inter).
*   **المصادقة وقاعدة البيانات:** Supabase PostgreSQL & Supabase Auth.
*   **الرسومات البيانية:** Recharts لتحليل البيانات وتتبع وتدفق الإيرادات والمصروفات.
*   **التحقق وإدارة النماذج:** React Hook Form + Zod لضمان سلامة المدخلات كالأرقام الضريبية والجوالات السعودية.
*   **التحكم بحالة البيانات:** TanStack Query (React Query) لاتصالات المستأجرين الفائقة السرعة.
*   **الحركة والتأثيرات:** Motion لتسهيل الانتقال وسلاسة الخطوات.

## 💾 ربط وتهيئة قاعدة بيانات Supabase

لربط المنصة بقاعدة بيانات سحابية حقيقية وتفعيل الحفظ الفعلي للمنشآت والمستخدمين:

### ١. تشغيل ملف SQL في Supabase
1. قم بإنشاء مشروع جديد على [Supabase](https://supabase.com).
2. ادخل إلى **SQL Editor** بالمشروع، واضغط على **New Query**.
3. انسخ كامل السطور البرمجية من ملف `supabase_schema.sql` (الموجود بجذر هذا المشروع)، والصقها داخل المحرر ثم اضغط **Run**.
   *   يقوم هذا السكريبت ببناء الجداول التالية: `profiles`, `organizations`, `organization_members`, `roles`, `permissions`, `role_permissions`, `branches`, `notifications`, `audit_logs`.
   *   يفعّل تلقائياً قواعد الحماية **RLS (Row Level Security)** لعزل بيانات كل منشأة عن المستخدمين الخارجيين.
   *   ينشئ **Trigger** تلقائي يقوم بإنشاء ملف تعريف (profile) فور تسجيل مستخدم جديد في المصادقة.

### ٢. إضافة متغيرات البيئة في Google AI Studio
انسخ قيم الاتصال من لوحة تحكم Supabase (Project Settings -> API)، ثم أضفها في نافذة **Secrets** داخل بيئة عمل **Google AI Studio Build** كالتالي:

```env
VITE_SUPABASE_URL="رابط المشروع السحابي الخاص بك"
VITE_SUPABASE_ANON_KEY="المفتاح العام للمشروع"
```

*ملاحظة: في حال لم تقم بإضافة مفاتيح المتغيرات، ستعمل المنصة تلقائياً بـ **وضع العرض التجريبي المعزول** لتمكينك والمشترين من تجربة كامل خصائص السجلات والتسجيل والمشروع بنقرة زر واحدة.*

## 💻 طريقة تشغيل وتطوير المشروع محلياً

لتشغيل خادم التطوير محلياً على جهازك:

```bash
# ١. تثبيت الحزم والمكتبات المعتمدة
npm install

# ٢. تشغيل خادم التطوير (على المنفذ 3000)
npm run dev

# ٣. بناء نسخة الإنتاج الجاهزة للنشر
npm run build

# ٤. فحص سلامة وتوافق أكواد الـ TypeScript
npm run lint
```

## ⚡ خطة النشر على منصة Vercel

تتوافق منصة لِدجرا بشكل مثالي مع النشر على Vercel كمنصة SPA سحابية خفيفة:

1. قم برفع المشروع على حسابك في GitHub.
2. ادخل إلى [Vercel](https://vercel.com) واضغط على **Add New Project** ثم استورد مستودع المشروع.
3. في مربع **Environment Variables**، قم بإضافة المفتاحين السابقين:
   *   `VITE_SUPABASE_URL`
   *   `VITE_SUPABASE_ANON_KEY`
4. اضغط على **Deploy** لإطلاق المنصة المحاسبية السحابية السعودية الخاصة بك على الإنترنت فوراً وبأعلى كفاءة!
